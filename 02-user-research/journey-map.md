# Journey Map

The moments inside a cross-brand purchase decision, and where prediction actually helps.

| Moment | State | FitMatch opportunity |
|---|---|---|
| 1. Browsing | Neutral, exploring | None |
| 2. Wants the item | Interested, low friction | None |
| 3. Reaches size selector on unfamiliar brand | Uncertainty spikes — this is the decision point | HIGH — primary intervention point |
| 4. Coping response | Over-orders sizes / reads reviews / abandons cart | Diagnostic — reveals the cost of no prediction |
| 5. Item arrives | Confirms or disproves the guess | Feeds back into fit history for next time |

**Critical finding:** Moment 4 (the coping response) is where existing behavior already reveals the cost of this problem — over-ordering and cart abandonment are both expensive workarounds for the same missing signal. The fix belongs at Moment 3, before the guess is made, not after the return process begins.
